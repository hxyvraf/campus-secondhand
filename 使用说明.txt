========================================
校园二手交易平台 - 使用说明（解压即用版）
========================================

一、这个包是什么
  一个完整可运行的前后端项目：Vue 3 前端 + Spring Boot 后端 + MySQL 数据库。
  前端页面已经打包进后端 jar，所以只需要启动一个服务、访问一个地址。

二、使用前需要装好两样东西（只装一次）
  1) JDK 17 或更高版本
     下载：https://adoptium.net/zh-CN/temurin/releases/?version=17&os=windows
     选 Windows x64 的 .msi 安装包，安装时勾选 Add to PATH。
     验证：打开命令提示符输入 java -version，能看到 17 或更高即可。
  2) MySQL 8（社区版）
     下载：https://dev.mysql.com/downloads/installer/
     安装时选 MySQL Server（或用默认的 Developer Default），端口保持 3306，
     记住安装过程中设置的 root 密码（首次配置要用到）。
     验证：Windows 的「服务」列表里能看到 MySQL80，且状态为“正在运行”。

三、三步上手
  1) 把压缩包解压出来（路径里可以带中文和空格，脚本已经适配）。
  2) 双击「启动系统.bat」。
     首次运行会依次问你 6 个问题，直接回车就用括号里的默认值：
       MySQL 地址 / 主机   -> 127.0.0.1
       MySQL 端口          -> 3306
       MySQL 账号          -> root
       MySQL 密码          -> 安装 MySQL 时设置的密码（输入时不显示）
       数据库名            -> campus_trade
       本机服务端口        -> 8080
     填完会先校验连接，再自动创建数据库、建表、写入初始数据。
  3) 浏览器会自动打开 http://localhost:8080 ，看到首页就成功了。
     以后每次使用，只需要双击「启动系统.bat」，不会再问配置问题。

五、常用操作
  · 停止服务：关闭标题为「校园二手交易平台 - 服务窗口」的那个窗口。
  · 改数据库账号或密码：双击「配置数据库.bat」重新填写（旧配置会自动备份为 application.yml.bak）。
  · 改服务端口：双击「配置数据库.bat」时在最后一项填新端口，或手动编辑
      backend\config\application.yml 里的 server.port，然后重新双击「启动系统.bat」；
      改完访问地址也要跟着变，例如改成 8081 就访问 http://localhost:8081 。
  · 重置数据（回到初始状态）：先关闭服务窗口，再双击「重置数据.bat」。
      注意：会删除数据库里已有数据，包括你自己注册的账号和发布的商品。
  · 接口文档（Swagger UI）：http://localhost:8080/swagger-ui.html

六、常见问题
  1) 提示“没有检测到 Java”或 Java 版本过低
     装 JDK 17 或更高版本，装完后重新打开窗口再试；仍不行就重启一次电脑让 PATH 生效。
  2) 提示连接失败 / Access denied
     多半是密码填错了：双击「配置数据库.bat」重填；
     或者 MySQL 服务没启动：在 Windows「服务」里启动 MySQL80。
  3) 提示端口被占用
     双击「配置数据库.bat」，把最后一项「本机服务端口」改成 8081 之类的空闲端口再启动。
  4) 第一次启动时 Windows 防火墙弹窗
     本地自用点「取消」或「允许访问」都可以，不影响 http://localhost 访问。
  5) 页面打不开 / 一片空白
     说明服务没起来或已经停了：看「服务窗口」里的报错，并确认 MySQL 正在运行。
  6) 杀毒软件拦截 .bat 文件
     所有脚本都是明文，位于 scripts 目录（.ps1 文件），可以直接查看内容后允许运行。

七、目录说明
  backend\              后端源码；target\campus-trade.jar 是打包好的可执行程序
  backend\config\       首次配置生成的本机配置（数据库连接、端口），发行包里不含此目录
  backend\uploads\      运行时上传的商品图片（自动生成）
  frontend\             前端源码（Vue 3 + Vite，改前端需要 Node.js 20+）
  docs\                 接口文档、测试计划 / 测试用例 / 测试报告与执行截图
  scripts\              各类脚本（启动、配置、打包、测试）
  启动系统.bat          免构建启动（日常使用推荐）
  配置数据库.bat        重新填写数据库连接与端口
  其余 .bat             源码开发与测试用（需要安装 Maven、Node.js）

八、想改代码后重新构建（可选）
  后端：装好 JDK 17+ 与 Maven 3.9+，双击「重新打包后端.bat」。
  前端：装好 Node.js 20+，在 frontend 目录执行 npm install 与 npm run build，
        再双击「打包前端到后端.bat」，把前端打进后端（单端口 8080 访问）。
