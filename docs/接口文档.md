> 版本：v1.0.0　|　接口数量：40 个　|　后端：Spring Boot 3.3.5 + MyBatis-Plus + MySQL 8　|　生成方式：`scripts/generate_api_doc.py`（读取运行中服务导出的 openapi.json + 真实执行报告）

## 一、怎么用这份文档

| 用途 | 地址 / 方式 |
| --- | --- |
| 在线接口文档（Swagger UI） | http://localhost:8080/swagger-ui.html |
| OpenAPI 原始定义 | http://localhost:8080/v3/api-docs （或本目录 openapi.json） |
| 导入 Postman / Apifox | `docs/postman/campus-trade.postman_collection.json` + `campus-trade.postman_environment.json` |
| 命令行批量执行 | 双击根目录 `跑接口测试-newman.bat` |

**鉴权约定**：除下列白名单接口外，所有接口都需要在请求头携带 `Authorization: Bearer {token}`，token 由登录接口返回。

- 白名单（匿名可访问）：`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/categories`、`GET /api/products`、`GET /api/products/{id}`、`GET /api/users/{id}`、`GET /api/users/{id}/products`
- 管理员接口（`/api/admin/**`）：需要 `admin` 账号登录后的 token，普通用户访问返回 403/40303。

## 二、公共约定

### 1. 统一响应体

```json
{ "code": 200, "message": "操作成功", "data": { } }
```

- `code`：业务返回码，200 表示成功，其他值见下方错误码表；
- `message`：面向用户的提示信息（前端可直接展示）；
- `data`：业务数据，失败时一般为 null；参数校验失败时为字段级错误列表 `[{"field": "price", "message": "价格不能低于 0.01 元"}]`。

### 2. HTTP 状态码与业务码

接口同时返回语义化 HTTP 状态码与业务码，便于做双层断言。

| HTTP 状态码 | 业务码 | 含义 | 典型场景 |
| --- | --- | --- | --- |
| 200 | 200 | 成功 | 查询、创建、修改成功 |
| 400 | 40001 | 参数校验失败 | 必填为空、长度超限、价格越界、分页参数非法、页码/ID 非数字 |
| 400 | 40002 | 文件类型不支持 | 上传非 jpg/jpeg/png 文件 |
| 400 | 40003 | 文件大小超限 | 上传超过 5MB 的图片 |
| 401 | 40101 | 未登录或登录已过期 | 未带 token、token 非法/过期访问受保护接口 |
| 401 | 40102 | 用户名或密码错误 | 登录时账号或密码不正确 |
| 403 | 40301 | 无权限操作该资源 | 修改他人商品、查看无关订单、标记他人消息、禁用自己 |
| 403 | 40302 | 账号已被禁用 | 被管理员禁用后继续调用接口或登录 |
| 403 | 40303 | 需要管理员权限 | 普通用户访问 /api/admin/** |
| 404 | 40401 | 资源不存在 | 商品/订单/消息/用户不存在 |
| 405 | 40500 | 请求方法不支持 | 用 GET 调 POST 接口等 |
| 409 | 40901 | 重复下单 | 同一买家对同一商品重复提交订单 |
| 409 | 40902 | 状态不允许该操作 | 重复下架、已完成订单再取消、删除有商品的分类 |
| 409 | 40903 | 商品当前不可交易 | 商品已锁定/已售出/已下架，或购买自己的商品 |
| 409 | 40904 | 用户名已存在 | 注册时用户名重复 |
| 415 | 41500 | Content-Type 不支持 | 请求头不是 application/json |
| 500 | 50000 | 服务器内部错误 | 未预期的服务端异常 |

### 3. 分页响应

列表接口的分页参数：`page`（默认 1，必须 ≥ 1）、`size`（默认 10，范围 1-100）。

```json
{ "code": 200, "message": "操作成功", "data": {
  "records": [], "total": 20, "page": 1, "size": 10, "pages": 2 } }
```

超过总页数时返回 200 与空 `records`（不会自动回到第一页）。

### 4. 其他约定

- 时间格式统一为 `yyyy-MM-dd HH:mm:ss`（东八区）；
- 金额为 `DECIMAL(10,2)`，取值范围 0.01 - 999999.99；
- 商品图片：先调 `POST /api/files/images` 上传，拿到 `/uploads/yyyyMMdd/xxx.png` 后再放入发布/编辑商品的 `imageUrls`；
- 初始数据里的示例图片地址形如 `/seed/p01.png`，由后端静态资源提供；
- 商品与订单的状态枚举见文末「状态字典」。

## 六、Postman / newman 使用说明

1. **导入**：Postman → Import → 选择 `docs/postman/campus-trade.postman_collection.json` 与 `campus-trade.postman_environment.json`，右上角环境选择「校园二手交易平台-本地环境」。
2. **执行顺序**：集合内按「认证 → 用户 → 分类 → 商品 → 收藏 → 订单 → 消息 → 管理端」排列，请整体运行（Collection Runner），不要打乱顺序：登录接口会写入 `buyerToken`/`sellerToken`/`seller2Token`/`adminToken`，发布商品会写入 `productId`，下单会写入 `orderId`，后续用例都依赖这些变量。
3. **断言方式**：每条请求都断言了 HTTP 状态码、业务返回码和关键业务字段；
4. **命令行执行**：在项目根目录执行 `newman run docs/postman/campus-trade.postman_collection.json -e docs/postman/campus-trade.postman_environment.json -r cli,htmlextra`，或直接双击 `跑接口测试-newman.bat`，HTML 报告输出到 `docs/测试执行证据/newman-report.html`。
5. **上传图片用例**：集合中的上传用例引用 `docs/postman/testdata/` 下的测试素材，因此 newman 需要在项目根目录执行（双击 bat 已自动处理）。
6. **超时关闭订单**：先把某条 `PENDING_CONFIRM` 订单的 `expire_at` 改成过去时间，再调用 `POST /api/admin/orders/timeout-scan`；具体 SQL 见《测试方案》。

## 七、状态字典

### 商品状态 ProductStatus

| 值 | 中文 | 说明 |
| --- | --- | --- |
| ON_SALE | 在售 | 可以被下单购买 |
| LOCKED | 交易中 | 已被某个买家下单锁定，其他买家不能下单 |
| SOLD | 已售出 | 订单完成后自动置为该状态 |
| OFF_SHELF | 已下架 | 卖家主动下架或管理员强制下架 |

### 订单状态 OrderStatus

| 值 | 中文 | 可执行操作 |
| --- | --- | --- |
| PENDING_CONFIRM | 待卖家确认 | 卖家确认、买卖双方取消、超时自动关闭 |
| CONFIRMED | 交易中 | 买家确认完成、买卖双方取消 |
| COMPLETED | 已完成 | 终态（不可取消），商品变为已售出 |
| CANCELED | 已取消 | 终态，商品回到在售 |
| TIMEOUT | 超时关闭 | 终态，卖家超时未确认，商品回到在售 |

状态流转图：

```
                     卖家确认                买家确认完成
PENDING_CONFIRM  ───────────►  CONFIRMED  ───────────►  COMPLETED（商品 SOLD）
      │                            │
      │ 取消 / 超时自动关闭          │ 取消
      ▼                            ▼
  CANCELED / TIMEOUT（商品回到 ON_SALE）
```

### 消息类型 MessageType

| 值 | 中文 | 触发时机 |
| --- | --- | --- |
| ORDER | 订单消息 | 下单、卖家确认、买家完成、订单取消、超时关闭 |
| FAVORITE | 收藏消息 | 卖家收到「商品被收藏」通知 |
| SYSTEM | 系统消息 | 平台通知（初始数据中的欢迎消息） |
