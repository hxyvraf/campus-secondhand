# 校园二手交易平台 测试点梳理（130+）

> 用途：需求评审后按模块拆解测试点，指导测试用例设计。
> 使用方法：把下面的层级大纲整体复制到 Xmind（或 Typora → 大纲视图），即可生成思维导图；每个编号对应一个测试点。

## 1. 注册登录（22 项）

1.1 注册
- 1.1.1 用户名 4-20 位字母/数字/下划线，边界：3 位、4 位、20 位、21 位
- 1.1.2 用户名含特殊字符（`@`、中文、空格）应被拦截
- 1.1.3 用户名重复注册应返回 409/40904
- 1.1.4 密码 6-20 位，边界：5 位、6 位、20 位、21 位
- 1.1.5 昵称必填，边界：1 位、20 位、21 位
- 1.1.6 手机号选填，格式校验（11 位、1 开头、非法字符）
- 1.1.7 邮箱选填，格式校验（缺少 `@`、缺少域名）
- 1.1.8 学校选填，长度上限 50 字
- 1.1.9 请求体为空对象时返回字段级错误明细
- 1.1.10 注册成功后密码以 BCrypt 存储，响应中不含密码字段

1.2 登录
- 1.2.1 正确账号密码登录成功，返回 token 与用户信息
- 1.2.2 密码错误返回 401/40102，提示不泄露账号是否存在
- 1.2.3 用户名不存在返回 401/40102
- 1.2.4 用户名为空 / 密码为空返回 400/40001
- 1.2.5 被管理员禁用的账号无法登录（403/40302）

1.3 鉴权
- 1.3.1 未携带 token 访问受保护接口返回 401/40101
- 1.3.2 token 非法（伪造/截断）返回 401/40101
- 1.3.3 token 过期后返回 401/40101（可改 `app.jwt.expire-minutes` 验证）
- 1.3.4 白名单接口匿名可访问（分类列表、商品列表/详情、用户主页、注册登录）
- 1.3.5 `/api/products/mine` 等接口未被白名单误放行
- 1.3.6 已登录用户调用白名单接口时仍能拿到个性化数据（如是否已收藏）
- 1.3.7 账号被禁用后，已签发的 token 立即失效（403/40302）

1.4 修改密码 / 退出
- 1.4.1 原密码错误返回 400/40001，提示「原密码不正确」
- 1.4.2 新密码与原密码相同被拦截
- 1.4.3 新密码长度不合法被拦截
- 1.4.4 修改成功后旧密码不可登录、新密码可登录
- 1.4.5 退出登录接口返回成功，前端清除本地 token

## 2. 商品发布与管理（28 项）

2.1 发布商品
- 2.1.1 标题必填，边界：1 字、50 字、51 字
- 2.1.2 标题含 emoji / 特殊字符可正常保存
- 2.1.3 描述选填，边界：0 字、1000 字、1001 字
- 2.1.4 售价必填，边界：0.01、999999.99、0.001、0、负数、1000000
- 2.1.5 售价支持两位小数，超过两位小数按规则保存或拦截
- 2.1.6 原价选填，可不填；填写时同样受范围约束
- 2.1.7 分类必填，分类不存在返回 400/40001
- 2.1.8 成色只能为：全新 / 九成新 / 八成新 / 七成新及以下
- 2.1.9 交易地点选填，上限 50 字
- 2.1.10 图片最多 5 张，第 6 张被拦截
- 2.1.11 未登录不能发布（401/40101）
- 2.1.12 发布成功后商品状态默认为「在售」，发布时间与浏览量为初始值

2.2 图片上传
- 2.2.1 jpg / jpeg / png 上传成功，返回可访问的 `/uploads/...` 地址
- 2.2.2 txt / exe / pdf 等类型被拦截（400/40002）
- 2.2.3 单张超过 5MB 被拦截（400/40003），等于 5MB 可通过
- 2.2.4 空文件上传被拦截
- 2.2.5 上传返回的地址可直接访问（HTTP 200）
- 2.2.6 未登录不能上传

2.3 商品列表（我发布的）
- 2.3.1 只返回当前登录用户发布的商品
- 2.3.2 支持按状态筛选（在售/交易中/已售出/已下架），状态参数非法返回 400
- 2.3.3 分页正确，包含交易中与已售出商品（与首页列表不同）

2.4 编辑 / 上下架 / 删除
- 2.4.1 本人可编辑在售或已下架商品
- 2.4.2 编辑他人商品返回 403/40301
- 2.4.3 编辑交易中/已售出商品返回 409/40902
- 2.4.4 编辑可替换图片，旧图片被清理
- 2.4.5 在售商品可下架，重复下架返回 409/40902
- 2.4.6 已下架商品可重新上架；对在售商品执行上架返回 409/40902
- 2.4.7 目标状态只允许 ON_SALE / OFF_SHELF
- 2.4.8 交易中的商品不可删除（409/40902）
- 2.4.9 删除为逻辑删除，删除后详情 404、列表不可见
- 2.4.10 商品不存在时统一返回 404/40401

## 3. 搜索与收藏（22 项）

3.1 搜索与筛选
- 3.1.1 关键词命中标题
- 3.1.2 关键词命中描述
- 3.1.3 关键词无结果时返回空列表与 total=0
- 3.1.4 关键词含特殊字符（`%`、`_`、单引号）不报错、不越权
- 3.1.5 按分类筛选，结果全部属于该分类
- 3.1.6 价格区间筛选（minPrice、maxPrice 组合）
- 3.1.7 minPrice > maxPrice 返回 400/40001
- 3.1.8 排序 latest / priceAsc / priceDesc / hot 结果正确
- 3.1.9 排序参数非法返回 400/40001
- 3.1.10 列表只返回在售商品，交易中/已售出/已下架不出现
- 3.1.11 列表包含分类名、卖家昵称、封面图等展示字段

3.2 分页
- 3.2.1 默认 page=1、size=10
- 3.2.2 page=0 返回 400
- 3.2.3 size=0 返回 400；size=100 通过；size=101 返回 400
- 3.2.4 page 非数字返回 400
- 3.2.5 超过总页数返回 200 与空 records
- 3.2.6 分页字段 total/page/size/pages 计算正确

3.3 商品详情
- 3.3.1 返回图片列表、分类名、卖家信息、状态中文名
- 3.3.2 每次访问浏览量 +1
- 3.3.3 登录用户返回 favorited 字段；匿名用户为 null
- 3.3.4 商品不存在返回 404；id 非数字返回 400

3.4 收藏
- 3.4.1 收藏成功，收藏数 +1
- 3.4.2 重复收藏幂等（返回 200 且提示已收藏，收藏数不重复增加）
- 3.4.3 取消收藏成功，收藏数 -1
- 3.4.4 未收藏时取消收藏幂等
- 3.4.5 收藏不存在的商品返回 404
- 3.4.6 我的收藏列表分页正确，含商品摘要字段
- 3.4.7 卖家收到「商品被收藏」消息（自己收藏自己的商品不产生消息）

## 4. 订单管理（28 项）

4.1 下单
- 4.1.1 正常下单成功，订单状态为待卖家确认，金额取商品当前售价
- 4.1.2 下单后商品状态变为交易中（LOCKED）
- 4.1.3 同一买家重复下单被拦截（409/40901），不生成重复订单
- 4.1.4 其他买家购买已锁定商品返回 409/40903
- 4.1.5 不能购买自己发布的商品（409/40903）
- 4.1.6 购买已售出/已下架商品返回 409/40903
- 4.1.7 商品不存在返回 404；商品 ID 为空返回 400
- 4.1.8 买家留言上限 200 字，201 字被拦截
- 4.1.9 未登录不能下单
- 4.1.10 下单生成订单号且唯一，写入超时时间 expireAt
- 4.1.11 卖家收到「收到新订单」消息

4.2 订单查询
- 4.2.1 买家视角只返回自己买到的订单
- 4.2.2 卖家视角只返回自己卖出的订单
- 4.2.3 按状态筛选正确（5 种状态）
- 4.2.4 角色参数非法返回 400
- 4.2.5 订单详情返回商品标题、封面、买卖双方昵称、金额与各阶段时间
- 4.2.6 无关用户查看订单返回 403/40301
- 4.2.7 订单不存在返回 404

4.3 状态流转
- 4.3.1 卖家可确认「待卖家确认」订单 → 交易中，记录 confirmedAt
- 4.3.2 买家确认订单（越权）返回 403/40301
- 4.3.3 重复确认返回 409/40902
- 4.3.4 买家可完成「交易中」订单 → 已完成，记录 finishedAt
- 4.3.5 卖家确认完成（越权）返回 403/40301
- 4.3.6 对未确认订单执行完成返回 409/40902
- 4.3.7 完成订单后商品状态变为已售出
- 4.3.8 已完成/已取消/超时订单不能再取消（409/40902）

4.4 取消与超时
- 4.4.1 买家可取消待确认订单，商品回到在售
- 4.4.2 卖家可取消待确认/交易中的订单
- 4.4.3 取消原因写入 cancelReason，未填写时使用默认原因
- 4.4.4 取消后对方收到「订单已取消」消息
- 4.4.5 超过 expireAt 的待确认订单被定时任务自动关闭为 TIMEOUT
- 4.4.6 超时关闭后商品回到在售，买卖双方均收到消息
- 4.4.7 管理端可手动触发超时扫描，返回关闭订单数
- 4.4.8 超时扫描不会影响交易中/已完成订单

## 5. 消息通知（14 项）

- 5.1 消息列表按时间倒序分页返回
- 5.2 可按 isRead 筛选未读/已读
- 5.3 可按 type 筛选订单/收藏/系统消息
- 5.4 未登录访问消息接口返回 401
- 5.5 未读消息数接口返回 count
- 5.6 下单、确认、完成、取消、超时分别触发对应消息
- 5.7 商品被收藏时卖家收到收藏消息
- 5.8 标记单条已读后未读数 -1
- 5.9 重复标记已读不报错
- 5.10 标记他人消息返回 403/40301
- 5.11 消息不存在返回 404
- 5.12 全部标记已读返回更新条数，未读数归零
- 5.13 前端导航栏红点每 30 秒轮询刷新
- 5.14 消息内容包含关键信息（商品标题、订单号、原因）

## 6. 管理端（20 项）

6.1 权限
- 6.1.1 普通用户访问 `/api/admin/**` 返回 403/40303
- 6.1.2 未登录访问管理端返回 401
- 6.1.3 普通用户前端看不到管理入口，直接输入 URL 被路由拦截

6.2 商品管理
- 6.2.1 管理端列表返回全部状态商品
- 6.2.2 支持关键词与状态筛选
- 6.2.3 强制下架在售商品成功
- 6.2.4 交易中/已售出商品不能强制下架（409/40902）
- 6.2.5 商品不存在返回 404

6.3 用户管理
- 6.3.1 用户列表支持账号/昵称搜索，返回角色、状态、在售商品数
- 6.3.2 禁用用户成功，被禁用用户立即无法调用接口（403/40302）且无法登录
- 6.3.3 启用用户后恢复正常访问
- 6.3.4 管理员不能禁用自己（403/40301）
- 6.3.5 不能禁用其他管理员账号
- 6.3.6 状态值非法（如 5）返回 400

6.4 分类维护
- 6.4.1 新增分类成功，名称重复被拦截
- 6.4.2 修改分类名称与排序值成功
- 6.4.3 删除空分类成功
- 6.4.4 删除有商品的分类返回 409/40902
- 6.4.5 分类名称超过 20 字被拦截

6.5 订单与工具
- 6.5.1 管理员可强制取消待确认/交易中的订单，商品回到在售
- 6.5.2 管理员可手动触发订单超时扫描并返回关闭数量

## 7. 通用与接口规范（10 项）

- 7.1 所有接口返回统一结构 `{code, message, data}`
- 7.2 HTTP 状态码与业务码一一对应（400↔40001、401↔40101、403↔40301/40302/40303、404↔40401、409↔40901/40902/40903/40904）
- 7.3 参数校验失败时 data 返回字段级错误列表
- 7.4 请求方法不支持返回 405/40500（如 GET 调注册接口）
- 7.5 Content-Type 非 application/json 返回 415/41500
- 7.6 时间字段格式统一为 `yyyy-MM-dd HH:mm:ss`
- 7.7 金额保留两位小数
- 7.8 接口响应不返回密码等敏感字段
- 7.9 接口响应时间在可接受范围（本地平均 14ms）
- 7.10 所有接口可在 Swagger UI 中查看并直接调试
